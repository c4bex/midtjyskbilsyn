# Privatliv og sikkerhed

- Gem kun nødvendige oplysninger: navn, kontaktoplysninger, kunde-/virksomhedsreference og køretøjsdata.
- Telefon og e-mail skal behandles som beskyttede felter og må ikke vises i fejlloggen.
- API-nøgler, tokens og adgangskoder må kun ligge i serverens hemmelighedslager.
- Testdata skal være fiktive eller anonymiserede.
- Sletning skal ske som kontrolleret anonymisering, så revisionshistorik stadig kan dokumenteres.
- Alle ændringer i booking, faktura, åbningstider, medarbejdere og integrationer logges.
- Adgang gives efter mindste privilegium og gennemgås ved medarbejderændringer.
