# Midtjysk Bilsyn – version 1

## Før produktionsbrug

- [ ] Login og rollebegrænsning er koblet til den rigtige brugeridentitet.
- [ ] Databasebackup og dokumenteret gendannelse er testet.
- [ ] Kunder, køretøjer og bookinger kan importeres kontrolleret.
- [ ] Ferie, fridage, pauser og åbningstider påvirker kapaciteten.
- [ ] Fakturaklargøring beskytter mod fejl og dobbeltfakturering.
- [ ] Fejllog og genoptagelse af fejlede handlinger er gennemgået.
- [ ] Persondata, sletning og hemmelighedshåndtering er dokumenteret.
- [ ] Mobil, tablet, desktop og tastaturbetjening er testet.
- [ ] Kort driftsvejledning er klar til medarbejderne.

Integrationer aktiveres først, når dokumentationen, testdata og parallelkørsel er godkendt.
